# Kanban Task Board

## About

This is a simple Kanban Task Board that I built using **HTML, CSS, and JavaScript**. The project helped me practice working with the DOM, handling user interactions, and using Local Storage to keep data after refreshing the page.

## Features

* Add new tasks
* Edit tasks
* Delete tasks
* Drag and drop tasks between columns
* Search tasks by title or description
* Filter tasks by priority
* Save tasks with Local Storage
* Responsive layout

## Technologies

* HTML5
* CSS3
* JavaScript (ES6)
* HTML5 Drag and Drop API
* Local Storage

## Project Structure

```text
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open **index.html** in your browser.

No installation or additional packages are needed.
